### Description

This project implement singletone programmer pattern

### How to build

- Create new directory for building
- Run cmake command in this directory
- Run make command and wait untill build is finished

Example:

`mkdir build_directory`

`cmake /path/to/source/CMakeLists.txt`

`make -j number_of_threads`

### How to test

Run in terminal executionable file *singletone*

Example:

`./singletone`

You will see some digit in terminal.

Enjoy it! :)
